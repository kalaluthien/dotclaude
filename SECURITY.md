# Security

Report a vulnerability privately through GitHub's private vulnerability reporting: open the form at https://github.com/kalaluthien/dotclaude/security/advisories/new. Never put it in a public issue or comment, since anyone can read those before a fix lands.

Include:

- the file, such as a hook or script, with the commit you saw it in;
- what an attacker can do, and what they need first;
- the steps or a minimal input that shows it.

The owner answers in the advisory and credits you there once a fix lands, unless you ask not to be named.
