# docs

the only markdown `docs/` holds.

- [memory-pool-layout.html](memory-pool-layout.html) — doc, a decision page: which
  decisions shaped this machine's memory pools, 2026-07-26 onward, and what
  each one gave up. Holds what the two retired `history-*` pool memories held.
- [memory-pool-lookup.html](memory-pool-lookup.html) — view: how one session
  finds its memory pool, one flow diagram.
- [dotclaude-counts.html](dotclaude-counts.html) — dashboard: skills, hooks,
  `CLAUDE.md` lines and memories against their prior or target, as of its build.
- [kind-picker.html](kind-picker.html) — ui: walks the kinds' tie-break to name
  a page's kind.
