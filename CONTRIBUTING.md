# Contributing

- **Outside pull requests are not accepted**: the owner's sessions run this setup straight from `main`, so only they change it; a pull request from anyone else is closed unread.
- **Issues are welcome**: a bug, a question or an idea goes in an issue that says what should change and why.
- **Fork freely**: the README's [Steal it](README.md#steal-it) says how to copy a part; make your own changes in your fork.
- **Security**: a vulnerability goes through [SECURITY.md](SECURITY.md), never an issue.
- **Rules**: [CLAUDE.md](CLAUDE.md) holds the preferences every change follows.
